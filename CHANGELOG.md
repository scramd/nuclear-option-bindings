# Changelog

## 0.1.1 (2026-11-14)

- Shorter help text under each binding setting. It no longer tells the player to open F1, because they read it there.

## 0.1.0 (2026-10-30)

First release, taken from the bindings that several Nuclear Option client mods already use.

- One binding setting per action, edited in ConfigurationManager (F1) by pressing the control: keys and key combinations, mouse buttons, named gamepad controls, and buttons, hat directions and axis directions on any other device.
- Saved BepInEx `KeyboardShortcut` text converts in place.
- `NUCLEAR_BINDINGS_GENERIC` and `InputContext.ExtraBlock` for other Rewired games.
